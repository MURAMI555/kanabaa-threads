麗子のこと

昔、夜のお店のカウンターに立ってたの。
カウンターに座る女の子は、だいたい男の話をしに来るわ。
男のお客は、だいたい言い訳をしに来る。

両方を聞いてると、分かってくるのよ。
男の言葉と、男の行動は、別の生き物だって。

「忙しい」って言う男が、本当に忙しいこともある。
でも、本当に大事な相手には、忙しくても時間を作るのも男なの。
その違いが分からなくて、待ちくたびれてる女の子を、アタシはたくさん見てきた。

アタシはね、男にも女にも肩入れしないの。
男の気持ちも分かるし、女の気持ちも分かる。
オネエって、ちょうどその間の席に座ってるのよ。

使うのは、彼の星座と生年月日。
それと、男を見てきた目。
霊感はないわ。だから、未来を言い切ったりはしない。
アタシが言えるのは、彼がどういう男で、アナタが次に何をすればいいか。それだけよ。

泣きたい夜は、泣いていいの。
でも、明日の予定は、自分で決めなさい。
そのための背中なら、いくらでも押してあげるわ。

どっちの味方もしないわよ。
決めるのはアナタ。アタシは、背中を押すだけ。

こんな言葉で止まってる子へ

  • 「忙しい」と言われて、もう3週間
  • 「落ち着いたら会おう」の、落ち着く日が来ない
  • 既読はつく。返事は来ない
  • 好きって言葉はくれるのに、会う日が決まらない
  • 待つのに疲れたけど、やめ方も分からない

ひとつでも当てはまるなら、
カウンター、空いてるわよ。
