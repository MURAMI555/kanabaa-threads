い ち婆さんのこと

若いころは、ホステスをしていた。
男の本音と、女の人の泣き顔を、毎晩見てきたよ。

そのあと店を何軒も回して、何千人の客と社員を見てきた。

そこで分かったことは、ひとつだけ。

人は、言葉より
行動に本音が出る。

「好きだよ」と言う男より、黙って時間を作る男のほうが本気だった。
「落ち着いたら」と言う男の「落ち着いたら」は、来ないことのほうが多かった。

だから婆さんは、彼の言葉じゃなく、彼の動きを視るんだがね。

に待つ女は負ける

夜の店で、待ってる女の人をたくさん見てきた。

連絡を待つ。
「そのうち」を待つ。
彼が変わるのを待つ。

やさしい人ほど、待つんだよ。
相手の都合を考えて、自分の気持ちは後回しにして。

でもね、待ってるあいだに、自分のほうがすり減っていく。
婆さんは、それが一番もったいないと思ってる。

待つ以外にできることは、
ひとつはある。

初視は、それを見つけるためのもんだよ。

よ ん初視の読み方

  • 一人になれる時間に開く。
    仕事の合間や、人のいる所で読むと、半分しか入らないよ。
  • 一度目は、流して読む。
    最後まで、止まらずに。
  • 二度目は、手が止まったところを覚えておく。
    「なんで分かるの」と思ったところ、認めたくないのに認めたところ。そこが、あんたが一人で我慢してきた場所だよ。
  • 違うと思ったところも、そのままにしない。
    違うと思ったら、どう違うか、ひと言返しておくれ。婆さんはちゃんと読む。

ご待つあいだに、ひとつだけ

初視が届くまで、彼への連絡をひとつ足さないでおくれ。
